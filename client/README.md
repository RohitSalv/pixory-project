> **Client-side interface for the Pixory Ecosystem.**  
> Built with Angular 20, Tailwind CSS v4, and Lucide.

Pixory is a premium, AI-powered digital sanctuary for your memories. It provides a stunning, glassmorphism-inspired interface for uploading, browsing, and searching images enriched with natural language descriptions and semantic tags generated by the [Pixory Backend](../server).

---

## 🚀 Key Features

- **Intelligence-First Gallery**: A clean, responsive grid that displays AI-generated metadata, descriptions, and searchable tags for every photo.
- **Glassmorphism UI**: High-end aesthetic with subtle blur effects, micro-animations, and luxurious dark-mode optimization.
- **Natural Language Search**: Semantic search capabilities—find photos by content (e.g., "sunset", "mountain") using the AI metadata engine.
- **Smart Upload System**: Drag-and-drop interface with real-time status tracking for both binary upload and asynchronous AI analysis stages.
- **Secure Token Management**: Seamlessly handles JWT access and refresh token rotation in the background for an uninterrupted session.
- **Responsive Design**: Fluid experience optimized for Desktop, Tablet, and Mobile devices.

---

## 🛠 Tech Stack

- **Framework**: Angular 20 (Signals-based architecture, Standalone Components)
- **Styling**: Tailwind CSS v4 (Using the latest high-performance JIT engine)
- **Icons**: Lucide Angular
- **State Management**: Reactive RxJS & Angular Signals
- **Animations**: Angular Browser Animations Module
- **Environment**: Support for `.env` variables via modern build tools

---

## 🎨 Design Philosophy

Pixory follows a **"Luxury Calm"** design approach to photo management:
- **Glassmorphism**: Minimalist blur effects and semi-transparent layers for a modern, premium feel.
- **Subtle Feedback**: Smooth transitions and skeleton loaders instead of jarring progress bars.
- **Dark-First**: Optimized for a luxurious dark aesthetic that makes your photography the focus.

## ⚙️ Configuration

This client uses environment variables for easy configuration. Create a `.env` file in this directory:

```bash
# API Configuration (Default for Local Backend)
BACKEND_API_URL=http://localhost:8092/api
AUTH_API_URL=http://localhost:8092/api/auth
FILES_API_URL=http://localhost:8092/api/v1/files

# Application Settings
PRODUCTION=false
```

## 🏗 Getting Started

This directory contains the frontend client. To run it as part of the monorepo:

### Prerequisites
- **Node.js**: v18 or higher (LTS recommended)
- **Angular CLI**: Latest version (`npm install -g @angular/cli`)
- **Pixory Backend**: Running locally on port 8092

### Installation & Run
1.  **Install dependencies**:
    ```bash
    npm install
    ```
2.  **Start development server**:
    ```bash
    npm start
    ```
3.  **View application**: 
    Open your browser at `http://localhost:4200`

---

## 🛡 Security & Auth

The frontend implements a production-grade security layer:
- **HttpInterceptors**: Automatically attaches Bearer tokens to all outgoing API requests.
- **Silent Refresh**: Automatically detects token expiration and refreshes the session without user intervention.
- **Route Guards**: Protects all private routes and ensures a secure session is active before viewing gallery data.
