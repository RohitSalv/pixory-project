# Pixory Documentation & Assets

This directory contains the visual assets, architectural diagrams, and historical documentation for the Pixory project.

## 📁 Directory Structure

- **[/Docs](./Docs)**: High-resolution architecture diagrams and branding assets (logos).
- **[/JOURNEY_MDs](./JOURNEY_MDs)**: Detailed markdown files documenting the technical journey, challenges faced, and lessons learned during the development of Pixory.

## 🏗 Architecture
The system architecture follows a decoupled Monorepo pattern, integrating Spring Boot with Angular and Google Gemini AI. You can find the full diagram in the `Docs` folder.

## 📄 Project Journey
For a deep dive into how this project was built, refer to the files in `JOURNEY_MDs`. This is highly recommended for those interested in the engineering decisions behind the AI pipeline and security architecture.
